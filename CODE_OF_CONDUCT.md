# Code of Conduct

This is a personal repository. It isn't a community project, but if
anyone else ever interacts with it (issues, pull requests, discussions),
the following applies:

- Be respectful and constructive in comments and reviews.
- Focus feedback on the code, documentation, or automation — not the
  person.
- Harassment, insulting or derogatory comments, and other unprofessional
  conduct will not be tolerated and may result in comments being
  removed or interactions being blocked.

Concerns can be raised by contacting the repository owner directly.
