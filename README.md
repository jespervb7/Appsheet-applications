# Appsheet-applications

Documentation and automation for my AppSheet applications: how each app
is structured, and the Python/GitHub Actions automation that supports
them (e.g. reading/writing Google Sheets data).

## Repository layout

- [`docs/`](docs/) — documentation per AppSheet application.
- [`src/`](src/) — Python automation code.
- [`.github/workflows/`](.github/workflows/) — GitHub Actions that run the automation.
